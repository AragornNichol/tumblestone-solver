Tumblestone Solver

Use R,G,B,Y,P for the coloured stones, # for blockers (use 0 if they start open), and % to indicate wildcards.

Click here for an explanation of the wildcards

Blockers - Solid blocks which can only be cleared by emptying the rest of their row.
Toggling Blockers - Blocker which swaps between being solid and not, allowing every other shot to pass through it. Cannot be cleared.
Wildcards - Can be used in place of any colour, but only once each per puzzle.
Colour Lock - Prevents two triplets of the same colour from being made consecutively.
Sprouts - The block removed with the first shot of each triplet is added to the top of the column it was removed from.
Staggered Locks - Chequerboard pattern across the blocks which prevents half of them from being used. All locks toggle after each shot made.
Row Shift - The blocks in some selected row will all shift one column to the right after each shot.
Double Shot - Each shot takes two blocks.
Column Flipping - When the final block of a triplet is removed, its entire column flips upside down.
Second Shot Pass Through - For the second shot of each triplet, the lowest block in every column becomes transparent, allowing the shot to pass through it.
Countdown Blockers - When a block is removed, it is replaced by a blocker which lasts until three shots have been taken.
